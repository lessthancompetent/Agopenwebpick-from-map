Primed start

          

            
            
            
            
          

          
          

        

        

          
What it does

          
Primes the boom or simulates application while parked: for the run time, the target rate is computed as if the machine were travelling at the simulated speed. Turn on the section switches you want to prime first — only sections that are on will run. Cancel by pressing PRM again or turning the master off. Not available with a maintained switch type.

Valve wiring

          

            
            
            
          

        

        

          
Relay drivers

          

            
            
            
          

          
3-wire is the default for most installations: one switched signal wire, with the valve powered from its own supply and managing open/close itself. Choose 2-wire for a motorised or latching valve, where the driver has to power it in both directions.

          
        

      

    


    

      

        

          
Pins for the sensor selected above

255 means not connected. Changing a pin makes the module save and restart.

        

        

          
Relay output pins

          

            
            
            
            
            
            
            
            
          

          
Only used when the relays hang straight off micro pins — a board driving them through a PCA9685 or MCP23017 addresses them by channel and leaves every pin here at 255.

          
        

      

    


    

      

        

          
What each relay does

          

            
            
            
            
            
            
            
            
            
            
            
            
            
            
            
            
          

        

        

          
Flow/master valve

          

            
            
          

          
—

          
Live

          
—

          

            
            
          

          
Product only goes out when the master is on, a section is enabled, and — in auto — the guidance allows it. A relay set to Power is on whenever the module is.

        

      

    

    

      

        

          
Response

          

            
            
            
            
            
            
            
            
            
          

        

        

          
Timing and flow sensor

          

            
            
            
            
            
            
            
          

          
Tuning order: set min power to the least that moves the valve, max power to 100 and integral to 0. Raise the gain until the rate overshoots, then back it off. Only then add integral.

          
        

      

    


    

      

        

          
Wired subnet

          

            
            
            
            . 50 + module id
          

          
        

        

          
How the module is addressed

          
Ethernet uses a STATIC address: these three octets plus 50 + the module id, gateway .1. WiFi is different - it takes DHCP from whatever access point it joins, so that network decides its subnet, not this.

        

      

    


    

      

        

          
Board type

          

            
            
          

          
Commissioning

          
          
          
        

        

          
Before assigning an ID

          
A module adopts the ID unconditionally, so every board powered and reachable takes it - and two boards sharing an ID both stop working. Power only the board being commissioned.

          
After reflashing a module

          
A reflash wipes the module's saved settings. Set the wired subnet again on the Network tab, then use Send everything above - the module keeps no copy this app can read back.
